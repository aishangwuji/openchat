核心对话、工具、设置、资产四条主线**功能项已基本对齐**，差异集中在三类：

1. **鸿蒙有、移动端没有的 8 个功能/行为**（多为体验细节 + 3 个真实缺陷）；

## 二、鸿蒙有、移动端缺失（按影响排序）

1. **联网搜索开关不持久化**（`chat_controller.dart` `_enableWebSearch = true`，`setEnableWebSearch`
   只改内存）：用户关掉后重启又变开；且默认值与鸿蒙相反（鸿蒙默认关）。
2. **生图失败不能重试、中断态不恢复**：鸿蒙存 `imagePrompt` 并提供「重试」，
   启动时把 `generating` 改成 `failed` + 「生成被中断，可点重试」；移动端两者都没有，
   `imageState='generating'` 一旦落盘就是永久转圈。
3. **朗读不会随场景停止**：鸿蒙在离开对话页、切换会话、重新生成时停朗读；
   移动端 `TtsService` 只有按钮触发 stop，`ChatPage.dispose` / `switchSession` 都没停
   → 切到设置或另一个会话后音频继续播。
4. **「按住说话」语音模式**：鸿蒙输入区可整体切成按住说话（带键盘切回、松手转写、
   上滑取消）；移动端只有点按开始/停止。
5. **顶栏「朗读最后一条回答」**：鸿蒙有常驻喇叭；移动端只能滚到那条消息点朗读。
6. **图片「复制链接」**：鸿蒙 Markdown 图片操作行有预览/复制链接/浏览器打开；移动端只有预览。
7. **单条消息最多 3 个附件**：鸿蒙有明确上限与提示；移动端可无限追加。
8. **iOS 缺少相机/相册权限文案**：`Info.plist` 只有麦克风与 FaceID，
   缺 `NSCameraUsageDescription`、`NSPhotoLibraryUsageDescription` → iOS 选图/拍照会直接崩
   （App Store 审核也会拒）。

## 三、移动端有、鸿蒙没有（迁移后需决定去留）

1. **用户身份卡**：移动端仍完整（存储、编辑、提示词前缀、历史回放），鸿蒙已按「多余功能」
   整体删除。建议随转向一并删除，减少一条维护分支。
2. **7 家资产服务商**（多 stepfun / openrouter / novita）：保留即可。
3. **会话时间分组、来源底部面板、`[citation:N]` 角标**：移动端领先，保留。
4. **Key 存 Keychain/Keystore**：比鸿蒙 Preferences 明文强，保留。

## 四、发布与合规（真正阻塞，详见 TD-004）

1. **发布链路只有 HAP**：`scripts/release.ps1`、`docs/release.md` 都只构建/发布 `.hap`；
   `dist/` 里只有 `openchat-1.0.2.hap`，没有 APK/AAB。
2. **更新检查会把 HAP 当下载**：基线 `_pickAsset` 优先级是 `.hap → .apk → 首个资产`，
   Android 用户点更新会拿到 HAP。并行会话正在改（未提交）；方向正确，但 WIP 在
   「没有 APK」时仍回退到首个资产（HAP），应改为回退 release 页面。
3. **包名仍是占位**：`com.example.openchat`（Android `applicationId` / iOS bundle id），
   不能上架；`com.example.*` 必须换自有域名反写。
4. **默认 Flutter 图标 / 启动页、无隐私政策、无商店材料**（TD-004 第 4、5 条）。
5. **iOS 未编译**（无 Xcode），且权限文案缺失。
6. **版本号双源**：`pubspec.yaml version` 与 `app_version.dart` 必须手动同步；
   发布脚本只改鸿蒙 `app.json5`。转向后应改为单一来源 + 校验。
7. **无 CI**：没有 analyze/test/build 流水线；转向后所有发布都靠本机手工。
8. **无崩溃/遥测**：pubspec 无 Crashlytics/Sentry；上架后线上问题不可见。
9. **无数据迁移**：鸿蒙会话/Key 存在鸿蒙 Preferences，移动端无法读取；两端都没有导出/导入。
   需要产品决策：做导出导入，或明示老用户重新开始。
10. **合规**：无隐私政策/服务条款/数据删除入口；生图无 AI 标识；会话正文明文。

## 五、建议顺序

**P0（宣布转向之前）**：APK/AAB 发布链路（签名、资产、文档、CI）→ 包名/图标/隐私政策 →
iOS 权限与构建 → 更新检查只认 APK → Android 真机回归（语音/相机/文件/朗读/生图）。

**P1**：搜索开关持久化并对齐默认值 → 生图重试与中断恢复 → 朗读生命周期停止 →
崩溃上报 → AI 标识。

**P2**：按住说话语音模式 → 顶栏朗读 → 图片复制链接 → 附件 3 个上限 →
删除用户身份卡 → 全量 i18n（如出海）。
