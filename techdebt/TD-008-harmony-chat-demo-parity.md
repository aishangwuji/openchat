# TD-008 鸿蒙端未跟进「对话页对齐 chat-demo」改版

- 状态：待评估
- 影响范围：鸿蒙端 `pages/ChatView.ets`（来源胶囊、朗读按钮、语音输入）、
  `pages/Settings.ets`、`components/*`
- 首次登记：2026-11-23
- 参照：`mobile/` 端 2026-11-23 的四批改动（提交 `3e750cf`、`178bbfe`、`f79b44e`、`c78d88e`）

## 现象 / 缺口

移动端参照 DeepSeek 官方 chat-demo 重做了对话页的四处体验，鸿蒙端仍是旧版：

| 能力 | 移动端（新） | 鸿蒙端（旧） |
|---|---|---|
| 搜索结果 | 站点缩略图摘要行 + 底部来源面板（序号/图标/日期/标题/摘要） | 来源胶囊（最多 5 个 + `+N`），点击直接开浏览器 |
| 引用角标 | 识别 `[citation:N]`（官方格式）+ 点开来源面板高亮 | 只按 annotations 偏移插标，正文 token 可能残留 |
| 侧边栏 | 今天/昨天/7 天/30 天/年月分组 + 行内「更多」 | 扁平列表 + 长按菜单 |
| Markdown | 代码块语言/复制、表格描边、引用块、行内代码接主题 token | fluid-markdown + 部分自定义，未统一 |
| 语音 | 录音状态条（计时/波形/取消）、识别中可取消 | 录音按钮有状态但不显示计时/波形 |
| 朗读 | 全局单实例 + 跳动音柱 | 单条按钮，状态在各自组件内 |

## 建议做法

1. 先做低风险、纯收益的：引用 token 兼容（`[citation:N]`）与来源面板——两者共用现有
   `WebSearchService.parseCitations` 与 `ChatView` 来源列表，不引入新依赖。
2. 侧边栏分组：逻辑同 `mobile/lib/core/utils/session_groups.dart`，鸿蒙端是自己画的
   历史面板，只需在 `ChatView` 的会话列表构建处插入分组标题。
3. 语音状态条与朗读单实例需要改 `ChatView` 的输入区与 `TtsService` 回调，
   建议与「录音权限异常处理」一起排期。
4. Markdown 外观：鸿蒙端用 fluid-markdown，代码块/表格样式通过其 theme 映射，
   不追求与移动端逐像素一致。

## 备注

移动端本轮刻意没有照搬 demo 的桌面能力：分栏搜索面板、hover 卡片、Mermaid、KaTeX、
继续生成（需 beta 接口 + `prefix:true`）、会话导入导出。若后续要在鸿蒙端做，
先确认产品需求再接，避免为演示功能增加维护面。
